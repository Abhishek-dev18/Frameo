HTTP stateless है. हर request नई होती है, server को याद नहीं रहता कि आप कौन हो. तो क्या हर click पर password डालोगे?
---
नहीं. Login सफल होते ही server एक random session ID बनाता है, और Set-Cookie header से browser को दे देता है. फिर browser हर request के साथ वो cookie खुद भेजता है.

इसलिए session cookie ही आपका pass है. वो चोरी हुई, तो password की ज़रूरत ही नहीं. Tech में — cookie पर HttpOnly, Secure और SameSite flags लगाओ, और logout पर server से session मिटाओ.
