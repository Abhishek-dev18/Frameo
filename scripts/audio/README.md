# Audio for Debug Diaries videos

- `voice.py <voice-dir>`: text-to-speech with Piper (offline). Voices come from
  https://github.com/rhasspy/piper/releases/tag/v0.0.2 (e.g. voice-en-us-ryan-high.tar.gz).
  **Licence:** these voices are CC BY-NC-SA / non-commercial. Fine for an unmonetised channel;
  switch to your own voice or a commercially licensed TTS before monetising.
- `music.py`: generates an original lo-fi bed (no copyright), 30 s.
- Mix (voice lines placed at each scene, music ducked under the voice): see the ffmpeg command
  in the session notes; sections start at 0.6 s, 10.3 s and 21.6 s for the 30 s entry template.
